The first version of lumen: a terminal you can work in all day.

## What is in it

- **Tabs and splits**, built in. A new tab or pane opens in the folder of the current one. Panes can be resized with the mouse, and one pane can fill the tab for a while.
- **A window frame of its own**: the tabs are in the title bar.
- **A cursor that glows.** It gives off light, dims instead of going out when it blinks, and glides between cells.
- **Selection** by character, word, line and block, a clipboard, a scrollback of 10,000 lines, and a text size per pane.
- **Mouse reports** for programs that use the mouse, such as vim and htop.
- **A config file** in TOML: font, window, cursor, colors. The `[colors]` table has the same shape as Alacritty's, so the colors of a theme written for Alacritty can be pasted in.
- **True color**, and a see-through window with blur where the desktop can do it.

Under it are two well-tested parts: the terminal engine of Alacritty, and GPUI, the UI framework of the Zed editor. See [How it works](/docs/how-it-works/).
