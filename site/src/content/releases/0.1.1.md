## New

- **`prewarm = true`** keeps one shell started ahead of time, in the folder of the current pane. A new tab then shows a finished prompt the moment it opens, however long your shell takes to start. Measured with fish, from the key press to a finished prompt: about 30 ms instead of about 230 ms. It is off by default, because your shell's startup files then run before you ask for the tab. See [Instant tabs](/docs/instant-tabs/).
