lumen 0.4.0 learned where your commands are. This release shows what they cost, and tells you when one is over.

![lumen with three tabs. The first reads "cargo build" and shows 5.6 and 4.1G beside its name. A light at the right of the title bar is lit, and a note under it reads "busy: cpu at 13.2 of 16 cores, most from cargo build (5.6 cores)"](/shots/machine.png)

## The machine

These need [pulse](https://github.com/Vaspyyy/pulse), the tool of the family that says what the machine is busy with. It went public on the day of this release, and `go install github.com/Vaspyyy/pulse@latest` installs it. Without pulse, this part changes nothing.

- **A light in the title bar** is lit while the machine is busy. Rest the mouse on it to read why, and click it to open pulse in a tab.
- **A tab says what it costs**: the CPU cores and the memory of everything its panes have started, beside the tab's name. With a few tabs open you see which one the fans are for.
- **A command's mark says what it costs.** While the command runs: `running for 8.2 s · 5.6 cores · 4.1 GB`. When it has ended: `done in 48.2 s · up to 8.9 GB`.

![A command's mark with a note beside it: "running for 8.2 s, 5.6 cores, 4.1 GB"](/shots/command-cost.png)

See [The machine](/docs/machine/).

## For every program

- **Notifications.** A program can ask for your attention (OSC 777 and OSC 9, which other terminals know too). lumen passes it on only when you are not looking: the tab gets a dot, and the desktop a notification that leads back to the pane. `pulse run` uses it to say that a long run is over. See [Commands](/docs/commands/#when-a-program-has-something-to-tell).
- **Links that put a command at your prompt.** A program can print a link that stands for a command. A click types it at the prompt and leaves `Enter` to you: a link never runs anything. lumen shows all of what a click would type before you click, and takes the click only on text you can see, in the pane you are typing in. See [Files and links](/docs/files-and-links/#links-that-type-a-command).

![A line that reads "next: pulse tree 4821.kfx", underlined under the mouse, with a note above it: "pulse tree 4821.kfx, click puts it at the prompt"](/shots/prompt-link.png)

## Settings

- `[pulse]` with `enabled` and `every`, and `notifications`. See [Configuration](/docs/configuration/).

The Android app is the one from 0.3.0 with a new version number.
