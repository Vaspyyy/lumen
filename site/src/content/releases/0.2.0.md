This is the release where lumen starts to do what other terminals don't: it knows that a name in a listing is a file.

## Files

- **A name in a `glint` listing is the file.** A click copies it to the clipboard, as a file manager's Copy does: paste it into a folder, a mail, a chat. `Ctrl+Click` opens it in its program. It can be dragged out of the window into another program (on Wayland), or onto a pane, which types its path. See [Files and links](/docs/files-and-links/).
- **Other links** a program prints (web pages, `file://` links from `ls --hyperlink`) open with `Ctrl+Click`. Hold `Shift` to select text that is a link.
- **Files dropped on a pane** from a file manager are typed as their paths, quoted for the shell.
- A click copies only where the link's text is the file's name. A link that says one thing and leads to another file is treated like any other link, and needs `Ctrl`.

## Pictures

- lumen draws what a program sends with the kitty graphics protocol, in place, and it scrolls with the text. `glint --thumbs` shows real thumbnails with it. See [Pictures](/docs/images/).
- PNG and raw pixels, sent in the escape sequence or as a file, at their own size or fitted to a number of columns or rows.
- A pane keeps up to 320 MB of pictures (the oldest go first), and one larger than 4096 pixels on a side is scaled down.
- Not there yet: animations, and placement by placeholder characters.

## Search

- `Ctrl+Shift+F` searches what the pane has printed, scrollback included. `Enter` goes to the match before, `Shift+Enter` to the one after, `Esc` closes. See [Search](/docs/search/).
- The query is plain text. It ignores case unless it has a capital letter in it.

## Also new

- **The kitty keyboard protocol**, for programs that ask for it: an editor can tell `Tab` from `Ctrl+I` and `Enter` from `Shift+Enter`.
- **The config file is taken on when you save it.** lumen says so at the bottom of the window. A file with a mistake in it changes nothing, and the window says what is wrong.
- **Tabs move** when you drag one onto another.
- **Splits open at once** with `prewarm = true`, as new tabs already did.
- **Text an input method is composing** is shown at the cursor.

## Under the hood

- The thread that reads what a program prints is lumen's own now. Pictures arrive in escape sequences that the terminal engine drops, so lumen takes them out of the stream first.
- Every push is formatted, linted and tested by CI.
