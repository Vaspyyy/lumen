Until now lumen had to be built from source, which takes a Rust toolchain and a few minutes. From this version on, every release comes ready to install.

## New

- **A package for Debian and Ubuntu.** A `.deb` that `apt` installs, with the libraries lumen needs.
- **A package for Fedora and openSUSE.** An `.rpm` for `dnf` and `zypper`.
- **A package for Arch**, and for what is built on it, such as CachyOS, EndeavourOS and Manjaro.
- **One command for the others.** It needs no root: the program goes into `~/.local/bin`, the launcher entry and the icons into `~/.local/share`.

  ```sh
  curl -fsSL https://vaspyyy.github.io/lumen/install.sh | sh
  ```

- **Checksums.** Every release lists the SHA-256 of its files, and GitHub attests that they were built from this repository.

[Install](/docs/install/) has the commands for each of them.

## Fixed

- **lumen starts on a system with uncommon fonts.** It ended with an error right away when none of a handful of well-known fonts was installed, even with other fonts there. lumen now takes what the desktop uses for plain text, or any font there is, for its tab titles and its search field. Without a single font, it says so.
