This release closes the gaps the last two left open.

## Fixed

- **A background that a program sets is painted.** Scripts that switch a terminal to another theme, such as base16-shell, set the background, the text and the cursor to new colors. lumen took the new text color and went on painting the theme's background, so a light theme came out as dark text on a dark pane. The pane now takes all of them: the background fills the whole pane, and the cursor and lumen's own marks follow. Other panes and tabs keep the theme. See [Colors](/docs/colors/#colors-a-program-sets).
- **A prompt that is written again stays one command.** A shell writes its prompt again under a list of completions, after `Ctrl+L`, and when the window changes its width. lumen took some of these copies for a new prompt, and after the window was made narrower, zsh with a prompt on the right could leave the marks of commands off by a line. The prompt now stays one command wherever the shell writes it again, and what is left of its earlier copy is no command and no output: it has no mark, and it is not copied with what the command before it printed.
- **Prompts beside a command are not read as the command.** zsh's prompt at the right of the line, and the `> ` that bash and zsh put before a further line of a command, were taken for typed text where lumen reads a command from the screen. They are marked as prompts now, so a command of several lines is named as you typed it.
- **pulse is found when it is installed later.** lumen looked for [pulse](https://github.com/Vaspyyy/pulse) once, when it started. It now looks again every half minute until it finds it, so the light and the numbers on tabs show up in the lumen that is open.

bash and zsh get the new marks with the next tab you open: they come from the line `lumen shell-integration` that is in your startup file already.

## For programs

- `OSC 133 ; P` is read: `P;k=r`, `P;k=c` and `P;k=s` begin a prompt beside what is typed, which the next `B` ends. See [For programs](/docs/for-programs/#marks-for-commands).

The Android app is the one from 0.3.0 with a new version number.
