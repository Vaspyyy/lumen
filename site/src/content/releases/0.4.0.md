Until now, what a pane printed was one long stream of text to lumen. From this release on it knows the commands in it.

![Three commands in lumen with a mark beside each prompt: faint for one that went well, red for one that failed, lit for one that still runs. A note above the first reads "done in 1 ms, click copies the output", and a second tab has a green dot](/shots/commands.png)

## Commands

- **Every command has a mark** in the margin beside its prompt: lit while it runs, red when it failed, faint otherwise. Move the mouse onto it and lumen says how it went: `done in 2.4 s`, `exit 1 after 12 ms`.
- **A click on the mark copies what the command printed**, and selects it so you see what you got. `Ctrl+Shift+O` does the same for the last command.
- **`Ctrl+Shift+Up` and `Ctrl+Shift+Down` go from command to command.** No more scrolling back through a long build to find where it began.
- **A tab says what happened in it.** A tab you are not looking at shows a grey dot while a command runs there, a green one when it has ended, a red one when it failed. Start a build, go elsewhere, and come back when the dot turns.
- **fish 4 needs no setup.** bash and zsh need one line in their startup file, which `lumen shell-integration` provides. The marks are a standard (OSC 133) that other terminals read too.

See [Commands](/docs/commands/).

## Places in code and web addresses

- **`Ctrl+Click` on `src/main.rs:42:9` opens that line in your editor.** lumen reads the forms compilers, test runners and searches print: `file:line`, `file:line:column`, `file(line,column)`, and Python's `File "x.py", line 42`. crux, seek and recap print places this way.
- **A web address in plain text opens with `Ctrl+Click`**, as do files and folders a program names. Until now only what a program had marked as a link did.
- **Only what is there is a link.** Hold `Ctrl`, and lumen underlines what it can follow. A path is looked for from the folder its command ran in, and in the folders above it.
- **Your editor** is `$VISUAL` or `$EDITOR`, or `command` in the new `[editor]` table of the config. An editor of the terminal opens in a new tab, one with a window of its own beside lumen.

See [Files and links](/docs/files-and-links/#web-addresses-and-places-in-code).

## Also new

- **The bell** puts a dot on a tab you are not looking at. It still makes no sound.
- **The window has a title**: that of its current tab. Task bars and window lists showed nothing before.

## Fixed

- Hidden text (the style programs use for a password they don't want shown) was readable under a block cursor.

The Android app is the one from 0.3.0 with a new version number.
