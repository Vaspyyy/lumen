lumen's command line now follows the tools it hosts.

## Changed

- **`-V` prints the version.** It is the short flag for `--version` in glint, crux, recap, seek and pulse too; crux needs `-v` for `--verbose`. `lumen -v` still prints the version, as it did before. See [Command line](/docs/command-line/).
- **An unknown flag is told in one line**, as the tools tell it: `lumen: unknown flag --bogus (see lumen --help)`. This holds for `lumen pair`, `lumen attach` and `lumen sessions` too. A word that is no command says `unknown command`.
- **`lumen --help` begins with `✦ lumen` and the version**, like the help of the tools, and its headings are colored on a terminal unless `NO_COLOR` is set.

The install script knows a lumen by the start of its help, and it knows this one and the ones before it.

The Android app is the one from 0.3.0 with a new version number.
