title: New text keeps the line ending it replaces
summary: In a file with mixed line endings, new text that ends in a line break takes the ending of the text it replaces, not that of the next line.
---

## Fixed

- **New text that ends in a line break keeps the replaced line's ending.** In a file with mixed line endings (some lines end in `\r\n`, the others in `\n`), new text with more line breaks than the old text took the ending of the next line for its last one. Now it takes the ending of the old text's last line break, when the old text ends with one.
