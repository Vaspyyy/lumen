## Fixed

- **Replacing a whole definition keeps the line ending of its last line.** In a file with mixed line endings (some lines end in `\r\n`, as on Windows, the others in `\n`), the `\r\n` at the end of the definition was lost.
- **A file that ends without a line break still does** after `SEARCH all` deletes its last lines.
- **`--diff` shows the right line and the right old text for deleted last lines**, also after a `\r\n` and with `SEARCH all`.
- **When nothing is written, every folder splice made for new files goes again.** With several new files in a batch that failed, some of those folders could stay behind.
