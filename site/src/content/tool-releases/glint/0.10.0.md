## New

- **Marks in a folder of projects.** In a folder that isn't a repository itself, such as `glint -A ~/projects`, the map opens up to three recently active projects. Until now it marked nothing in them: only a single repository's map had marks. Now each project it opens gets its own marks, as in a repository map, and its own part of the `context:` line. A part is named by the shortest path that tells projects with the same name apart (`ws1/alpha: …; ws2/alpha: …`). Projects shown as one line stay as they are.
- **Other repositories are left alone.** The context reads git without taking its locks, so it never rewrites another project's index (git's list of what is staged).
- **It stays within the budget.** The `context:` line takes a line the map leaves free, or else the place of one glance line (the one-line look into a closed project).

## Fixed

- **The note "N dirs not expanded" counts every closed folder with entries**, closed projects without a glance line too. With context it could say "2 dirs not expanded" where it said "3" without, or go away.

## Underneath

- Built on Prism 0.8.0: outlines no longer list definitions that sit inside multi-line strings or comments (raw strings, template literals, heredocs, docstrings), and symbols end in the right place more often.
