## Changed

- **`--json` prints one envelope** in [Prism](https://github.com/Vaspyyy/prism)'s shared format, `prism/1`, as seek, recap and crux do. An envelope is one JSON document with the same outer shape in every tool: the repository (root, branch, HEAD, uncommitted changes), then the result, or on failure an error with a code (`usage` or `failed`). glint exits with the same code as without `--json`.
- **A listing's entries are in `result.items`**, with `result.dir` the folder their paths are relative to. An empty folder gives `[]`. A list stops at 10,000 entries, and `truncated` says when it did.
- **Breaking:** the old bare array is gone. A script that read it needs `.result.items`, for example `glint --json | jq '.result.items[]'`. A symlink's target is `link_target` now, not `target`, which every tool's JSON keeps for refs.
- **Views without JSON say so.** `-P`, `-C`, `-M`, `--thumbs`, `-i`, `-W` and `-A` on a folder refuse `--json` with a usage error, instead of printing something else.

## New

- **`glint -A --json <file>` gives a file and its outline.** It has what the text header shows (lines, size, modified time, mode, kind, image size, git status, last commit) and the file's symbols, each with its ref, its first and last line and its signature.
