## New

- **`glint -A` says what a project is.** After a `glint -A`, agents still opened the README only to learn what the project was. The header now has an `about:` line with the README's first paragraph of prose, without its headings, badges, links and emphasis, and cut to at most 220 characters, at the end of a sentence where it can. It shows in a git repository or a project folder, and not with `--since` or `--changed`.
