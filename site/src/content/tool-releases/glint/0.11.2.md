This came on the same day as [lumen 0.5.2](/releases/0.5.2/), which made the same change.

## Changed

- **`-V` prints the version.** It is the short flag for `--version` now, as in crux, recap, seek, pulse and lumen (crux needs `-v` for `--verbose`). `glint -v` still prints the version, as it did before.
- **An unknown flag is told in one line**, as the other tools tell it: `glint: unknown flag --bogus (see glint --help)`, instead of `unknown shorthand flag: 'V' in -V`.
