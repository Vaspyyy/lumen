glint now marks what you are working on, the way seek, recap and crux do, through [Prism](https://github.com/Vaspyyy/prism)'s shared context.

## New

- **Files committed on this branch get `[branch]`.** In a `glint -A` map, a file committed on the current branch since it left the default branch is marked `[branch]`, and folders count them (`[1 branch]`). A file with uncommitted changes keeps its `[M]` or `[new]`, which says more.
- **Changed symbols are marked.** In outlines (`glint -A <file>`, and maps with `--outline`), a symbol gets `[changed]` when it has uncommitted changes and `[branch]` when the branch changed it.
- **A `context:` line at the top says what the marks cover**, one line for the whole run, even across repositories:

  ```
  context: 1 changed symbol vs HEAD, 1 symbol changed on this branch since 453ae32
  ```

- `glint -A --json <file>` carries the marks, and the envelope's `context`.

## What it costs

- **Plain listings cost nothing extra.** The context loads only in these modes and only for what is listed, while glint reads the tree.
- **It never takes room from listed files.** In a full map, the `context:` line takes the place of a glance line (the one-line look into a folder), never of a line that lists files.
- `--no-context`, or `PRISM_NO_CONTEXT=1`, turns it off.

## Fixed

- **`glint -A --outline` no longer hangs on a link to `/dev/zero`.** Prism now reads only regular files to outline them.
