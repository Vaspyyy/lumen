## Fixed

- **`Segmentation fault` and jest's `✕` lines are errors.** Both were missed.
- **pino's levels are read.** pino, a logger for Node.js, writes its level as a number: `"level":40` is a warning now, 50 and 60 are errors.
- **Of a level field and a level word, the one that comes first decides.** `ERROR failed to set level=debug` is an error, and `level=info msg="set ERROR handler"` is not. The first wasn't counted.
- **Code and prose files are always text.** A short `.py` file with a comma in each line (`import os, sys`) was read as a table. Text of no known kind needs five rows that split evenly to be a table now, not three.
- **A `.csv` file is split at the delimiter that fits most of its rows**, even when one row has a field more or less.
- **A dotfile is a file.** With something on standard input, a single argument that starts with a dot is a jq path, unless it names a file. A folder like `.cache`, or a dotfile like `.eslintrc.json` that isn't there, was taken as a path too. Now peek says that `.cache` is a folder and that the file doesn't exist.
- **A path into an empty object says so**: `no key "zz" in .a[], an empty object`, instead of `its keys:` with nothing after it.
