## Fixed

- **A compiler's warning is a warning.** peek counted every line of the form `path:line:col: message` as an error, so `src/main.rs:4:2: warning: unused variable` was an error, and so were the `note:` lines under it. After such a place, `warning:` and `note:` decide now.
- **A passing test stays a pass** whatever its name says. `ok  pkg/ERROR 0.1s` was counted as an error.
- **Broken JSON is reported.** Text that starts with `{` but isn't valid JSON was shown as plain text. peek now says where it breaks, and that `--as text` reads it as text.
- **A `.csv` file with one or two rows** is split at its delimiter, so its columns are named.
- **A key that is in an object twice** shows its last value on the card and in the printed JSON, as a path already did. The card said `1 to 2` for `{"x":1,"x":2}`.
- **A path through JSON Lines says how many values along the way had nothing there**, as it already did in a JSON document.
