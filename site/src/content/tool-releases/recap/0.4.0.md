recap now shares what you are working on with glint, seek and crux, through [Prism](https://github.com/Vaspyyy/prism), the library they share. It is on by default, never hides a result, and says when it marks or fills in something.

## Context

- **The commit you look at becomes the focus.** `recap show abc123` and a comparison of two commits, such as `recap main...feature`, record that commit or range and the symbols it changed. seek and crux then mark those symbols `[focus]`. The working tree, `--staged` and `recap log` don't set the focus. It is kept in the git folder (`.git/prism/`), for each worktree and agent session, and is forgotten after an hour.
- **`--show` falls back to the focus.** When nothing in the working tree matches, `recap --show NAME` shows the match in the focus, and its first line says so: `context: nothing matches in the working tree; showing focus commit b681ef1`. For a range it names the commits the range stood for, so the run can be repeated after the branch names have moved on. With a revision, `--staged` or a line number it never falls back.
- **What failed is marked.** Changed symbols that failed in crux's last run get `[failing]`, and changes in the working tree to symbols the focus changed get `[focus]`. A first line that starts with `context:` names where the marks come from, for example `context: last run: crux go test ./... failed (just now)`.
- **A `next:` line says what to run next.** It suggests `seek` for the most important changed symbol that still exists, as in `next: seek internal/files/files.go:List   definition and uses by name`, and `recap … --show` with a ref when a change's lines didn't fit in the overview.
- **Context never costs a listed change.** The `context:` and `next:` lines take room only from changed lines shown inline. When there are none to give up, they come on top.
- **`--no-context`**, or `PRISM_NO_CONTEXT=1`, reads and records nothing. The output then depends only on the arguments and the files.
- `--json` carries the same: `context` for what the run used, `marks` on each symbol, and `next` for the suggestions.

See [Context](https://github.com/Vaspyyy/recap/blob/main/README.md#context).
