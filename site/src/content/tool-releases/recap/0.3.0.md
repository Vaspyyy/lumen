## New

- **`--json` prints one JSON document instead of the text**, for programs that use what recap found. JSON is a plain text format that programs read easily. It comes in the same envelope that every tool built on [Prism](https://github.com/Vaspyyy/prism) prints (`prism/1`), with recap's result inside.
- **What is in it**: the two sides compared, each file with its status and line counts, and each changed symbol with its ref (the same name as in the text), its old ref when it was renamed, signature changes, and where moved or extracted code came from. `recap show` adds the commit, `recap log` the commits with their files, and `--show` the whole diff of each symbol. Commit dates are real timestamps.
- **Errors are JSON too.** When recap fails, the document has a code instead: `usage`, `ambiguous`, `failed`, or `no_match`, which lists every ref that did change so a program can pick one. The exit code is the same as without `--json`.
- **Nothing is cut to fit a screen.** Lists are complete up to 10,000 items, or `-b N` items when `-b` is given, and `truncated` says when something was left out.
- `-p` can't be combined with `--json`, and says so.

The text is still the default, and it is what agents should read: it says the same in far fewer words. See [JSON](https://github.com/Vaspyyy/recap/blob/main/README.md#json).
