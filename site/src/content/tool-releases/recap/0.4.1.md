title: No hang on special files
summary: recap no longer hangs on a link to a pipe or a device in the working tree, and reads it the way git does. Your git settings can no longer garble what it reports.
---

## Fixed

- **No hang on special files.** A plain `recap` hung when the working tree had a symlink to a named pipe (a bug since 0.3.0), and a symlink to `/dev/zero` filled the memory. recap now reads a symlink the way git stores it, as the path it points to, and never follows it. A link that changed its target shows the old and the new path.
- **Pipes, sockets and devices are left out, as git leaves them out.** A tracked file that was replaced by one made git's diff fail, and recap ended with an error. Now it is listed as deleted, with a note that says what is there instead. An untracked one is left out, as `git status` does.
- **Your git settings no longer change what recap reads.** recap runs git and reads what git prints. Settings such as `diff.submodule`, `diff.interHunkContext`, `color.diff` and `log.showSignature`, and the variables `GIT_DIFF_OPTS` and `GIT_*_PATHSPECS`, could garble or shift that text: after a changed submodule, for example, the files that came next got the wrong changed lines. recap's own git runs ignore them now.
- **A file that became a symlink, or a symlink that became a file**, no longer gives the files after it the wrong changed lines.
- **Paths the old side never had** (a staged file that became a pipe, the new path of a rename) are no longer listed as deleted.
- **`added` in `--json` counts the lines of a new, untracked file the way git does**: a symlink's target counts its lines instead of always 1, and a last line without a newline counts too. The text already counted them right.

## Underneath

- Built on [Prism](https://github.com/Vaspyyy/prism) 0.8.0, the library the tools share. An edit inside a string or a comment that spans several lines and only looks like a definition, such as `func Fake() {` in a Go raw string, counts as a change outside definitions. recap reported it as a change to a function that doesn't exist.
