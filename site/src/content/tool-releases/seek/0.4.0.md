seek now knows what you are working on without being told. The tools share it through [Prism](https://github.com/Vaspyyy/prism): what changed in git, what [recap](https://github.com/Vaspyyy/recap) showed last, and what failed in [crux](https://github.com/Vaspyyy/crux)'s last run.

## Context

- **A mark after a definition's name.** `[changed]` for one changed in the working tree, `[branch]` for one committed on this branch, `[focus]` for one changed in the commit recap last showed, `[failing]` for one that failed in crux's last run. The mark shows wherever seek names a definition: in the groups (`func List [focus]  L73-107`), in the header of a ref, and in `-d`.
- **Marked definitions come first**: first in their file, their files before the others, and first among several definitions of one name. Nothing is left out for it.
- **A first line says what was used**, when anything was marked or moved:

  ```
  context: 1 changed symbol vs HEAD; focus: commit b681ef1 (recap, 4 min ago)
  ```

- **It costs a few milliseconds of git**, run while seek searches. `--no-context` (or `PRISM_NO_CONTEXT=1`) turns it off, for scripts and tests that compare outputs: the output is the same, minus the marks and the `context:` line.

## Tests

- **With a ref as the pattern, hits in tests are labeled.** A hit in a Go, pytest or Rust test reads `(test, mentions List)`.
- **A `next:` line gives the crux command that runs those tests:**

  ```
  next: crux go test -run '^TestList$' ./internal/files/   runs the 1 test that mentions List
  ```

  It is worded by what seek knows. A test that names `List` "mentions" it, which doesn't say that it tests it, so seek never says "covers". When the command can run other tests too, such as one of the same name in another package, the line says so.
- These come from the search itself, not from the context, so `--no-context` keeps them.

## Also new

- **The new lines don't crowd out files.** The `context:` and `next:` lines take their room from detail (hit lines, code), never from a file that would be listed.
- **`--json` carries it all**: the marks, the context, a `mentions` link from each test to the definition, and the `next` commands.

See [Context](https://github.com/Vaspyyy/seek#context) in the README.
