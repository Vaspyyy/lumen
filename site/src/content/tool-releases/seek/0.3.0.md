## New

- **`--json` prints the search as one JSON document**, for programs, in every mode: a plain search, `-d`, `-s`, `-c`, `-l` and a ref. It says how the pattern was read, and holds the definitions found, every hit grouped by file and by the definition it is in, the files searched and skipped, and counts. Each definition has its ref, its lines, its doc comment's lines and its signature. Each hit has its line, the column of its first match, its text, its label and whether it sets the name.
- **No line budget in JSON**, unless you give `-b N`, which lists at most N hits.
- **Errors are JSON too**, on standard output, with the same exit codes as the text. A ref that names nothing gives `no_match` with the refs it may have meant, and bad arguments give `usage`.
- **One format for the family.** The document is [Prism](https://github.com/Vaspyyy/prism)'s envelope (`prism/1`), the shape glint, recap and crux use too.

Text stays the default, and it is still what an agent should read: it is shorter, and it says what it left out. See [JSON](https://github.com/Vaspyyy/seek#json) in the README.
