crux 0.3 said where a failure is. This release also says what it is in.

## New

- **An `in` line under each error and failed test** names the innermost function, method or type that holds its line: `in internal/group/group.go:multiline`. It is a ref, the way glint, seek, recap and crux all name a place in code, so it goes straight into `seek` (the definition and its callers) and `recap --show` (its changes).
- **A failed test names its own definition too**, on a `test` line, when the failure happened somewhere else, such as in a helper the test calls. A failure without a place gets an `in` line with the test itself:

  ```
  2 failed tests:
    TestAdd  calc/calc_test.go:7
      in calc/calc_test.go:check
      test calc/calc_test.go:TestAdd
      got 2, want 3
    TestNoMessage  calc/
      in calc/calc_test.go:TestNoMessage
  ```

  Go tests are looked up in their package's `_test.go` files, pytest tests by their node ID, and cargo tests only when exactly one function in the crate fits the name.
- **Where the line is, not what the code does.** crux finds the function with fast rules for each language, not with a compiler. Files outside the repository (the standard library, installed packages), lines outside any definition, and warnings get no `in` line.
- **The budget makes room for it.** The first error or failure keeps its `in` line along with its explanation. The others get theirs before any more code is shown.

The way refs are written is described in [Prism](https://github.com/Vaspyyy/prism), the parser the tools share.

## Also new

- **Colored help**, in the style of glint's. `crux --help` begins with `✦ crux` and the version, sorts the flags under headings, and ends with examples and a few things good to know. The colors show only on a terminal, and `NO_COLOR` turns them off.
- **A skill for agents.** `skill/SKILL.md` in the repository teaches Claude Code when to use crux and how to read its report. Copy it to `~/.claude/skills/crux/`.

## For contributors

- Every push is checked with gofmt, go vet and the tests, with Go's race detector, on Linux and macOS.
