## New

- **`crux --json <command>`** runs the command as usual and prints one JSON document instead of the report: the exit code (and the signal, when the command was killed), the test counts, and every error, failed test and warning with its place, the `in` ref of the function it is in, and the failed test's own ref.
- **It lists everything**, not only what the budget lets the text report show: up to 10,000 entries per list. With an explicit `-b` it lists what the text report would, and `truncated` says how much a limit left out.
- **One envelope for the family.** The document is in `prism/1`, the shared format of [Prism](https://github.com/Vaspyyy/prism) that glint, seek and recap print too, so one script can read them all.
- **Still crux.** It exits with the command's code and keeps the full log. Nothing else is printed, so even stdout and stderr together are one JSON document; `-v` streams the command's output to stderr. Bad flags, and `-r` with `--json`, are a usage error.

The text report is unchanged and stays the default. It is the one to read yourself or to give an agent: it is much shorter.
