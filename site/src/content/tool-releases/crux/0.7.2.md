## Changed

- **`-V` prints the version.** It is now the short flag for `--version`, as in glint, recap, seek, pulse and lumen, which got it on the same day (see [lumen 0.5.2](/releases/0.5.2/)). `-v` stays crux's short flag for `--verbose`.
- **`crux -v` without a command says so.** It printed the help, which looked like a version flag that didn't work. It now prints `crux: -v needs a command: crux -v <command> (the version is crux -V)` and exits with 2.
