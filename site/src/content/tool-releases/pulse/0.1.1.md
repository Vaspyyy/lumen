pulse's command line now follows the rest of the family. lumen made the same change on the same day, in [0.5.2](/releases/0.5.2/).

## Changed

- **`-V` prints the version**, as `--version` does. It is the short flag in glint, crux, recap, seek and lumen too. `-v` is not: `pulse -v` says `pulse: unknown flag -v (see pulse --help)`.
- **An unknown flag points to the help**, as the other tools do. So does an unknown flag of `pulse run`.
- **`pulse --help` begins with `✦ pulse` and the version**, like the help of the other tools. It is in sections (`USAGE`, `RUNS`, `FLAGS`, `GOOD TO KNOW`) with colored headings on a terminal, unless `NO_COLOR` is set, and it lists `-h` and `-V` now.
